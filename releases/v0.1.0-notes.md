The M0 baseline: the unmodified upstream **bf-5rh** build (raw 57,492 B) for the Baofeng AR-5RM — the port-feasibility milestone that proved open firmware runs on this hardware.

## What happened

Flashed to the NRF dev unit on 2026-11-24 via the web flasher, after a full stock-firmware backup and a successful bootloader probe. All 57 packages were ACKed and the radio rebooted into bf-5rh.

Verified on hardware (board **5RH10W-V05**): display (ST7735), keypad, up/down tuning, receiver (NOAA WX received at −42 dBm), TX/PA (after the BandLock setting was corrected via CPS), FM broadcast tuner (via the FM overlay app), external-flash storage, the CPS protocol, and overlay apps. Stock channels carried over intact — bf-5rh uses the stock flash layout.

This build is the baseline every fork change is measured against, and it establishes the app **BUILD_HASH 0xDEC616E9** that all catalog overlay apps are built against.

## Warning

Flashing is performed **only** through the web flasher, with all of its gates (backup, bootloader probe, SHA-256 confirmation) in place. Flash only a unit you intend to run custom firmware on — the stock unit stays stock.
