**Fork 1** — the first release of our fork of upstream bf-5rh: a slimmed core, plus the standby-screen theme system delivered as **one firmware variant per theme**. You pick a theme in the web flasher by flashing its variant; switching themes = flashing a different variant.

## What changed

- **Core slimming (safe cuts only).** A symbol-level audit of the M0 build found one real duplication: `TextBuf`'s `write_str`/`as_str` monomorphized at 9 capacities. They now delegate to shared non-generic cores. Theme-less base: 57,492 B → **57,096 B** (−396 B), no behavior change, no feature removed. Bigger candidate cuts are documented unapplied in `fork/FORK.md`.
- **Four theme variants**, each the slimmed core with exactly one compiled-in standby renderer (an earlier all-themes-in-one build hit 64,744 B against the 61,440 B app limit and was rejected; the per-variant design fits every theme with 4.3–7.2 KB to spare):
  - **APX Pro** (raw 57,092 B) — upstream geometry, palette-threaded, master-band focus border.
  - **Clean Modern** (raw 57,160 B) — card layout, per-card signal text, mic bar.
  - **Data Dense** (raw 56,920 B) — full 5×8 data sheet: RX+TX frequencies and tones, live RSSI, radio state, last-signal line.
  - **Minimal Dark** (raw 54,284 B) — one huge frequency (color carries RX/TX state), almost nothing else.

## Compatibility

- BUILD_HASH is **unchanged at `0xDEC616E9`** (the `abi` crate is untouched, verified from the build output and by `check_app.py`): **all 11 catalog overlay apps remain valid on every variant** — no app reinstalls needed when switching themes.
- Target hardware: AR-5RM, board 5RH10W-V05 (the dev unit the M0 baseline was verified on).
- **Status: built and verified by construction and `check_app`, but NOT yet flashed to hardware as of this release.** The first theme flash (Data Dense, then APX Pro to prove the swap) is a separate, explicitly approved step.

## Warning

Flashing is performed **only** through the web flasher, with all of its gates (backup, bootloader probe, SHA-256 confirmation) in place. Flash only the designated dev unit — the stock unit stays stock.
