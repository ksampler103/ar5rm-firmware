# AR-5RM teardown — NRF unit (2026-11-24)

Unit: Preston's second Baofeng AR-5RM (the spare / designated dev unit)
Version screen (hold 8): `5RHNRF` / Ver v0.14 / bf
Photos: this folder (lcd-module-back, rf-chip-1, rf-chip-2, lcd-fpc-closeup, pcb-full)

## Findings
- **PCB:** purple, silkscreen **5RB10W-V02** — same board family as amoxu's RE-documented hardware (5RB10W V01), one revision newer. Gold shield-can lands fitted but **no shield cans installed**. Layout: RF section top around the antenna port, battery contacts center (+ T −), MCU/flash at bottom. Two grey thermal pads over the PA devices.
- **RF transceiver:** QFN in the shielded RF area, house-marked **HTL7G06S01P / ETWT00D1 / 2414-JY**. The marking does not resolve to any public part number (checked 2026-11-24) — consistent with the solution provider's custom-marked parts (cf. the MCU's SYN2A-000 silkscreen). Identity as **BK4819** rests on the platform documentation (amoxu names BK4819 for this board position on V01); to be proven by BK4819 register behavior when we first run code on it. The first-flash experiment doubles as this test.
- **MCU:** LQFP-48 at board bottom, crystal adjacent. Top marking unreadable (residue/glare in photos). Expected SYN2A-000 = customized Artery AT32F421C8T7 per the RE project; SWD IDCODE read will confirm definitively.
- **External flash:** SOIC-8 beside the MCU — presumed the XMC 25QH16 (16 Mbit SPI) from amoxu's hardware table.
- **LCD module:** part number **GD018QQ198S-FPC-A0**, code 6883, on the flex tail. **14 contacts** (pin markers "1" and "14" printed at the ends of the contact field) — a serial-interface (SPI-class) module: power, backlight, and a handful of signals. Controller is chip-on-glass and still unnamed (same blank as amoxu's table), but the interface class is now pinned down, which is the part the port actually needs first.
